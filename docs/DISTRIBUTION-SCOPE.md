# 公开源码范围与分发边界

原專案核心及 Skill 已有公開儲存庫；本次 Windows 變更目前仍是本機提交，未由本任務推送或發布。公開可見的舊版源碼不代表 Windows 新命令已上線。原創程式碼授權與剪映整合、商業使用及跨電腦相容性是不同事項。

## 收录

- 已審閱的 macOS 無介面草稿、時間線編輯、資源校驗、關鍵影格、效果與輸出源碼；Windows 端只把已驗證的草稿、檢查、副本編輯、FFmpeg 與原生輸出列為支援。六種幾何蒙版、疊化轉場、輕微抖動在 Windows 仍未支援。
- 当前入口实际需要的草稿编解码、文件快照和目录锁定源码。
- Windows 固定依賴安裝腳本、`requirements-windows.txt`、pyJianYingDraft 固定基線的兩份修補檔及來源聲明；使用者在本機另行取得依賴與剪映。
- 脱敏后的结构蓝图、资源身份/哈希目录、测试、独立 Skill、构建脚本和声明。
- 本次明确授权的 IG 案例演示：`docs/media/` 中两份视频预览和两份抽帧图，按精确路径、大小和 SHA 放行；来源与处理见该目录说明。

## 不收录

- 剪映安装包、官方动态库、内置字体、效果包、缓存音效和 GPU 编译缓存。
- 除上述四份已授权演示衍生件之外的真实视频、音频、用户草稿、原生账号资料、bookmark、Cookie、Token、密钥或带签名 URL。
- 历史实验输出、原始截图/日志、旧版本已登记在线音效的专用变更流程。
- 已編譯的 macOS codec 與 Windows 原生橋接程式；使用者在本機從源碼建置，仍需滿足固定哈希。

旧资料只从此次发布范围排除，原始目录仍保留；不会为了发布而删除开发历史或上游声明。
