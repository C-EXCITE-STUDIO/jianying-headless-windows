# Windows 剪映本機版工作計劃

更新：2026-10-18。對標固定的原專案基線 `42b3d75`；本機已驗證環境為剪映 `11.5.0.14471`。以可編輯草稿及 Windows 原生 MP4 輸出為交付目標。

使用者要求暫緩六種蒙版、疊化轉場、輕微抖動的手動測試。這三項仍標示未支援，後續不以目前的資源檔或匯出成功推定效果已實現。必要的介面驗收集中到一份分章草稿。

## 執行順序與驗收

1. [x] **統一正式入口。** 把已驗證的 Windows 草稿橋接、素材安裝、原生匯出納入儲存庫命令，提供只檢查與實際執行模式。驗收：命令可從儲存庫呼叫；新草稿建立、搬移後可原生匯出並完整解碼；目標已存在時拒絕覆寫。
2. [x] **環境診斷與重裝。** 檢查剪映 DLL 版本和雜湊、MSVC、FFmpeg、Python 依賴、素材與草稿根目錄，固定相容依賴版本並提供可重現安裝步驟。驗收：健康環境與缺依賴環境各有清楚的檢查結果；正式流程在錯誤環境執行前終止。
3. [x] **文字對等缺口。** 支援文字 X/Y、縮放、旋轉線性關鍵影格及靜態透明度。驗收：計畫驗證、草稿材料回讀及 Windows 原生成片的文字位置／尺度／角度／透明度抽樣通過；如需人工驗收，合併到同一草稿。
4. [ ] **既有草稿檢查與副本編輯。** 支援只讀檢查本機既有草稿，並在新目錄中修改受支援欄位。驗收：原件雜湊不變；副本可回讀、原生再匯出並完整解碼；不支援的素材及效果明確拒絕。
5. [ ] **交付整理。** 更新 Windows 安裝與使用說明、版本相容範圍、功能清單、錯誤恢復及最小示例；整理測試和授權邊界。驗收：從乾淨目錄依說明可安裝、跑環境診斷、建立草稿並輸出 MP4；Git 狀態及發布內容可審查。未經使用者指示不推送或公開發布。

每一步完成後記錄驗證證據，再開始下一步。來源裁切／變速後的關鍵影格和單一 GIF 超長循環是基線以外的選做擴充。
