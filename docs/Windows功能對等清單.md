## 原案 `27c2627` 新增能力的 Windows 狀態

- macOS 11.6.0 新增草稿建立、既有草稿副本編輯與 `ui-export` 介面匯出驗證；這是 macOS 的版本配置。Windows 仍只驗證剪映 `11.5.0.14471`，命令入口在 Windows 拒絕 `ui-export`，但已有獨立的 Windows 原生 MP4 輸出路徑。不能以原案的 11.6.0 驗證推定 Windows 11.6.0 可用。
- macOS 副本編輯可處理換字體、複製或刪除片段、替換素材等更多操作；Windows `windows-edit` 仍限於上表已驗證的文字、軌道名及部分靜態位置／音量修改，且不能編輯剪映介面保存後的加密草稿。
- Openverse 音效搜尋及下載腳本已合併，部分離線測試可在 Windows 執行；依賴 `from-compiled` 的自動音效工作流尚未接入 Windows 正式入口，也沒有 Windows 端到端驗收。Windows 目前可照原有流程使用已備妥的本地音效檔。
- 上游的 `clonefile` 首頁索引修復針對 macOS。Windows 原生草稿與輸出流程仍須依本表各項證據判定，不從這項修復推論 Windows 功能已擴展。

## 驗收原則

- `created-unverified-in-app`、`copied-edited-unverified-in-app` 等狀態代表檔案流程完成，不能代替剪映介面的實際驗收。
- `native-export-encoded-and-decoded` 代表輸出符合媒體規格且完整解碼；仍需觀看重要畫面、聽取聲音。蒙版一類效果尤其需要實際像素證據。
- 使用者已在舊版綜合草稿確認「全部正常」的範圍保留；新增文字動態與副本編輯已合併到一份六章草稿，並由使用者確認介面驗收通過。
- 原專案本身未正式支援任意模板、雲端工程、任意效果組合和可靠可編輯複合片段，這些不列為 Windows 已完成對等能力。
